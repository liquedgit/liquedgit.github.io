# liquedgit.github.io

Personal site of Michael Bryan Chandra — Offensive Security Engineer. Built with Astro + Tailwind CSS, deployed to GitHub Pages via Actions.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build
```

Content lives in `src/data/` — e.g. update CAPT progress in `src/data/credentials.ts`.
`cv/` (local only, git-ignored) holds the resume.lol source.
